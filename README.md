# Saurabh Shukla — recruiter-first website

A static, GitHub-ready redesign of the [current website](https://personal-branding-website-chi-drab.vercel.app/). Open `index.html` to review it locally. No build step or package installation is required.

## Files

- `index.html` — page structure, copy, metadata and links
- `styles.css` — visual design and responsive layout
- `script.js` — mobile navigation and footer year
- `assets/` — existing portrait, award and certificate photos, résumé PDF, and new favicon

## Publish to the existing Vercel project

1. Copy these files to the existing website repository's published root, preserving the `assets/` folder. If the existing project publishes from `public/`, copy them there instead.
2. Keep the current Vercel project connected to that repository. Push the changes to its deployment branch.
3. Check the page on a phone and a laptop, then open the résumé, email, LinkedIn and DayPlan links.

## Content checks before sharing with recruiters

- The site labels **₹100 Cr+ as projected annual impact**, not realized savings. The linked résumé describes a ₹272 Cr business case; the page uses the more conservative public claim from the current website.
- **₹65L+ annual savings** comes from the linked résumé and is described there as finance validated.
- The page uses the linked résumé's **10-month plan vs 7-month delivery** for an AVL passenger-car program. The current site describes this as 30% ahead of schedule.
- The existing live page says recurring field failures fell **30%**, while the linked résumé says **50%**. That claim is omitted pending a confirmed figure.
- Replace the award and conference images with original photos, if available. The images downloaded from the current site are screenshots with carousel arrows near the edges; the layout visually crops them, but original images will look sharper.
- Confirm that the résumé PDF, email address, LinkedIn URL, role availability and 2026–27 IIM Lucknow status remain current before publishing.

## What changed

The first screen now leads with a clear professional identity, portrait, four proof points and direct actions. Detailed text became three selected case studies, two labeled comparison charts, a compact career timeline and a small evidence gallery. The charts use separate scales so unrelated measures are never compared as if they share a denominator. The layout adapts to mobile, includes keyboard navigation, reduced-motion support and descriptive image text.
