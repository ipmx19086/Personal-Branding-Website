# Saurabh Shukla — Personal Branding Website

Recruiter-facing personal branding website built as a static site.

## Files

All files are kept directly in the repository root for easier GitHub upload:

- `index.html`
- `styles.css`
- `script.js`
- `profile.png`
- `vercel.json`
- `README.md`
- `.gitignore`

## Run locally

Open `index.html` in a browser.

## Deploy on Vercel

1. Upload these files to your GitHub repository.
2. Sign in to Vercel.
3. Select **Add New → Project**.
4. Import the GitHub repository.
5. Framework Preset: **Other**.
6. Leave Build Command empty.
7. Leave Output Directory empty.
8. Click **Deploy**.

The profile image is referenced directly as `profile.png`, so no `assets` folder is required.
